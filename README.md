Projeto escolar como o objetivo de desenvolver algum jogo ou programa em alguma linguagem. O grupo "Ratinhos de Ótavio" escolheram recriar o jogo de tabuleiro ludo com a linguagem de python.

## Objetivo

Desenvolver uma versão digital do jogo de tabuleiro
Ludo, aplicando conceitos de programação e lógica.
